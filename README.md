# YoonCom-MakingVoiceReports


---

## ✅ 필수 구성 요소

| 기능            | 도구                              | 설명                                         |
|-----------------|-----------------------------------|----------------------------------------------|
| STT             | Whisper Large-v2                 | 정확도 우수, 다국어(한국어 포함), 로컬 실행 가능  |
| 문장 정제       | LLaMA 3 (7B 또는 13B)             | 문장 보정, 문체 정제, 포맷 맞춤                |
| PDF 생성        | Python FPDF or ReportLab         | 텍스트를 PDF로 변환 (한글 폰트 필요)             |
| 한글 폰트       | 나눔고딕, 본고딕 등 TTF            | PDF 생성 시 한글 깨짐 방지                     |

---

## ✳️ 선택 기능 (권장)

| 기능                    | 도구/방법                       | 설명                                           | 필요 여부     |
|-------------------------|----------------------------------|------------------------------------------------|----------------|
| 파일 업로더             | Python CLI, PyQt                | 음성 파일을 드래그 앤 드롭 처리                     | ⛔ 선택        |
| 자동 폴더 감지          | `watchdog`                      | 특정 폴더에 파일 넣으면 자동 처리 시작               | ⛔ 선택        |
| 한글 맞춤법 검사        | `py-hanspell`                   | 띄어쓰기, 오타 교정                               | ⛔ 선택        |
| PDF 시각화 강화         | `Jinja2` + `WeasyPrint`         | HTML로 스타일링된 PDF 생성                         | ⛔ 선택        |
| 사내 문서 참조(RAG)     | `LangChain`, `FAISS`            | 과거 보고서나 문서를 불러와 참고                    | ⛔ 고급 선택    |

## 🧠 개선 포인트 제안

- **프롬프트 튜닝**  
  → `"아래 템플릿에 맞춰 정리해줘"` 식으로 명확한 키워드 사용 (ex. `회의 주제:`, `결론:`)

- **구두점 보완**  
  → Whisper 출력은 거의 붙어 있으므로 `"구두점과 문법 보정"`을 명시적으로 요청

- **파일명 자동 생성**  
  → 날짜 기반 자동 이름 부여: `2025-05-03_회의보고서_마케팅팀.pdf`

## 🔐 로컬 보안을 위한 체크리스트

| 항목             | 설명                                                                 |
|------------------|----------------------------------------------------------------------|
| 모델 수동 다운로드 | Whisper, LLaMA 모델을 Hugging Face/GitHub에서 수동으로 받기                  |
| 인터넷 차단       | 실행 중 네트워크 요청 차단 (방화벽, 네트워크 차단 또는 격리 환경 구성)          |
| 경량 실행 전략    | VRAM 16GB 이하 환경에서는 LLaMA 7B + quantization으로 시작 추천               |

## 🖥️ OS 별 설치 팁

| OS      | 설치 포인트                                                    |
|---------|----------------------------------------------------------------|
| Windows | Whisper는 `conda` 환경에서 설치 권장, `ffmpeg` 수동 설치 필요       |
| Linux   | `apt install ffmpeg`, Python venv 환경 구성 쉬움                  |
| macOS   | Homebrew로 Whisper + Ollama 설치 가능 (간단)                      |
